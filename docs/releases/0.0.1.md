# 轻同步 0.0.1 正式版

支持 Android 8.0 及以上，采用 miuix 界面，连接手机文件夹与 OneDrive。正式版内部版本号为 4，可覆盖升级同签名的旧预览及开发版。

## 功能与本次完善

- 微软账号直接登录，支持单向上传、手动与定时同步、网络与充电条件、进度与记录。
- 首页、任务卡片、云端文件列表与历史页面采用统一的 miuix 样式。
- 双向曲库功能仍为预览：使用内容哈希与共同基线判断改动，修改前保存已观察版本，两端改动冲突时保留版本，历史恢复为副本。
- 下载及恢复先写临时文件并校验，保留原文件后再替换；持久操作日志用于下次同步恢复中断操作。
- 上传或云端移动响应丢失时核对实际结果；发现外部修改或不支持安全改名时停止操作。
- 删除传播默认关闭，需在任务设置中单独确认。启用后经过两次完整扫描及至少一分钟等待，以可恢复隔离方式传播，不永久删除文件。
- 扫描失败、云端根目录消失、批量缺失及删除与修改冲突时停止自动传播。
- 首次打开申请通知权限；启动时不检查 OneDrive 或同步文件夹，登录和目录授权在相关功能中操作。

## 已知限制

- 双向曲库已通过模拟器隔离集成测试，尚未完成真机与真实 OneDrive 的双向故障测试；建议先使用曲库副本。
- 两次文件改名不具备跨操作原子性，文件提供方的断电持久性仍需设备验证。
- 中断后遇到外部修改会保留文件与日志并停止，目前没有完整的冲突选择和取消恢复界面。
- Windows 普通 OneDrive 客户端不能保留轻同步尚未观察到的电脑中间版本。
- 历史、保留副本和临时文件占用存储，默认不清理；大曲库性能与厂商后台保活仍需长期验证。
- 定时同步最短间隔为 15 分钟，实际启动受安卓省电策略影响。“仅 Wi-Fi”使用系统不计费网络条件。
- 上传进程中断后可能需要重新上传文件，不承诺跨进程分片续传。

## 安装包

- `oh-my-sync-0.0.1.apk`：独立发行签名，供首次安装和发行版升级。
- `oh-my-sync-0.0.1-debug.apk`：调试签名，供覆盖本工程之前安装的测试或开发版，保留登录与任务数据。
- 两种签名无法互相覆盖；已有测试版请选择调试包，不要直接卸载后重装。
- `SHA256SUMS.txt` 提供两个安装包的校验值。
- 旧预览附件以 `preview` 名称保留；其源码保留在 `v0.0.1-preview` 标签。

## 验证

通过 39 项 JVM 单元测试、调试及发行构建和 lint 检查；两个 APK 均验证签名。MuMu 已通过 7 项安卓集成测试，使用独立目录、安卓文档提供方和模拟云盘，覆盖双向改动、冲突、删除隔离、墓碑后重新加入、中断恢复及扫描保护。真机已完成微软登录、单向上传与调试包覆盖升级验证；独立测试包被手机系统拒绝，未完成真机集成测试。
