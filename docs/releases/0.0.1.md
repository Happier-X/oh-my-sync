# 轻同步 0.0.1 预览版

首个可安装预览版，支持 Android 8.0 及以上。

## 界面调整

- 保留 miuix 风格，收紧首页概览、统计与空状态布局。
- 任务卡片区分手机目录和 OneDrive 路径，整理云端文件与版本历史入口。
- 云端文件列表独立滚动，账户页显示实际版本号，双向曲库功能标记为预览。

## 功能

- 微软账号直接登录，手机文件夹单向上传至 OneDrive。
- 手动及定时任务、网络和充电条件、同步进度与记录。
- 内容哈希及云端版本检查，分块上传、冲突保护。
- 双向曲库预览：共同基线判断增改、已观察版本归档、冲突保留，历史恢复为副本。

## 当前限制

- 单向上传已在真机验证；双向曲库尚未完成隔离目录的真机端到端验证，建议先用曲库副本测试。
- 删除只报告待确认项，不自动删除手机或云端文件。
- 尚未实现原子文件替换和跨进程操作日志。下载写入中断可能留下不完整当前文件，可从已备份历史恢复副本。
- Windows 端使用普通 OneDrive 客户端，无法保留轻同步尚未观察到的电脑中间版本。
- 历史版本占用手机和 OneDrive 空间，默认不清理；大曲库性能仍需验证。
- 定时同步最短间隔为 15 分钟，实际启动受安卓省电策略影响。“仅 Wi-Fi”使用系统不计费网络条件。

## 安装包

- `oh-my-sync-0.0.1.apk`：独立发行签名，供首次安装和后续发行版升级。
- `oh-my-sync-0.0.1-debug.apk`：调试签名，供覆盖此前由本工程安装的测试版本，保留现有登录和任务数据。
- 两种签名无法互相覆盖安装。已有测试版本应选择调试包；迁移到发行签名前请先记录任务配置，不要直接卸载后重装。
- `SHA256SUMS.txt` 提供两个安装包的校验值。

## 验证

本地通过 24 项单元测试、调试与发行构建、调试与发行 lint 检查；发行 APK 通过签名验证。新版调试包已覆盖安装到真机和 MuMu，保留原应用数据；已检查模拟器首页布局和真机任务页面内容。
